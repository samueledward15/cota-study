# مذاكرة الإكليريكية

موقع مذاكرة لمواد **الكلية الإكليريكية اللاهوتية بالإسكندرية** (دبلوم الطلبة · السنة الأولى).
بيشتغل على الموبايل والكمبيوتر، وينفع يتنزل كأبلكيشن (PWA)، ويشتغل من غير نت بعد أول فتحة.

موقع ثابت (HTML + JSON) من غير build، فأي رفع على `main` بيتنشر على Vercel لوحده.

## هيكل الملفات

```
index.html              ← الأبلكيشن كله (الشكل + المنطق)
subjects.json           ← قائمة المواد (اللي بتظهر في الصفحة الأولى)
map.json                ← خريطة البحر المتوسط والأماكن (مشتركة بين المواد)
manifest.webmanifest    ← بيانات الأبلكيشن عند التنزيل
sw.js                   ← الشغل من غير نت
img/                    ← هوية COTA (اللوجو، البردي، الزخارف)
icons/                  ← أيقونات الأبلكيشن
subjects/<id>/          ← مادة واحدة
    course.json         ← بيانات المادة وقائمة المحاضرات
    lec1.json … lecN.json
    img/                ← صور المادة (webp)
```

## إضافة مادة جديدة

1. اعمل فولدر `subjects/<id>/` (مثلًا `subjects/new-testament/`).
2. حط فيه `course.json` وملف لكل محاضرة `lecN.json` بنفس شكل ملفات تاريخ الكنيسة.
3. في `subjects.json` غيّر `"ready": false` لـ `true` للمادة دي.

المواد الجاهزة دلوقتي: تاريخ الكنيسة (١). المواد اللي جاية: العهد الجديد، العهد القديم، اللاهوت العقيدي.

### `course.json`

```json
{
  "title": "اسم المقرر الكامل",
  "course": "اسم الكورس القصير",
  "teacher": "أ. اسم المدرّس",
  "span": "الفترة أو الوصف (اختياري)",
  "description": "وصف المقرر (اختياري)",
  "goals": [["معرفيًا", "…"]],
  "lectures": [
    {"n": 1, "ord": "الأولى", "title": "…", "span": "…", "pages": "٢ – ١٤", "ready": true}
  ]
}
```

### `lecN.json`

| المفتاح | المحتوى |
|---|---|
| `title`, `span`, `summary[]` | العنوان والخلاصة |
| `sections[]` | الأجزاء: `id`, `title`, `kicker`, `page`, `part` (اختياري)، و`blocks[]` |
| `people[]` | الشخصيات: `id`, `name`, `role`, `img`, `facts[]` |
| `timeline[]` | `y` (رقم للترتيب، سالب = قبل الميلاد)، `d` (التاريخ المكتوب)، `x` (الحدث)، `big` |
| `maps{}` | خرايط `pins` أو `route` أو `spread` (اختياري) |
| `cards[]` | كروت الحفظ: `["سؤال", "إجابة"]` |
| `quiz[]` | أسئلة: `mcq`, `tf`, `fill`, `match`, `order`, `essay` |

أنواع الـ `blocks`: `p`, `sub`, `list`, `olist`, `quote`, `key`, `mnemonic`, `table`, `img`, `steps`, `flow`, `stats`, `map`, `person`.

لو مادة مفيهاش خط زمني أو خرايط أو شخصيات، التابات بتاعتها بتختفي لوحدها.

## التشغيل على جهازك

```bash
python3 -m http.server 8000   # وبعدين افتح http://localhost:8000
```
